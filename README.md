# Employee Field-Work Tracking System

Open `index.html` in a browser (GPS check-in needs https or localhost on most phones).

- `index.html` page structure
- `css/styles.css` styling
- `js/app.js` all app logic (login, daily check-in, attendance, approvals, Excel upload/export)
- `js/logos.js` embedded logo images
- `assets/favicon.png` browser icon

Demo: manager / admin123. Executive: E101 / 9840000101.
Data is stored in the browser (localStorage). A real deployment needs a server and database.
The Excel library loads from cdnjs, so an internet connection is needed for Excel export.
